# Львів пішки

## Технічне завдання

**Призначення.** Допомогти відвідувачеві спланувати коротку прогулянку центром Львова від Оперного театру через Вірменську вулицю до площі Ринок.

**Аудиторія.** Гості міста та львів’яни, які переглядають маршрут на телефоні або планують прогулянку за комп’ютером.

**Можливості.** Переглянути схему й послідовність трьох зупинок, дізнатися напрямок наступного переходу, перейти до порад або туристичного порталу, повернутися нагору. Усі посилання мають бути доступні з клавіатури.

**Структура.** Єдина сторінка index.html містить шапку з навігацією, вступ зі схемою, впорядкований список зупинок, блок порад і підвал.

**Дизайн.** Світлий паперовий фон, темно-зелений текст і теракотовий маршрут. Заголовки набрані шрифтом із засічками, основний текст — системним шрифтом без засічок.

**Технічні вимоги.** Семантичний HTML і окремий файл CSS. На вузькому екрані блоки розміщуються один під одним. Від 48 rem вступ займає дві колонки, а зупинки — три. Цільові браузери — сучасні Chrome та Firefox. Сторінка має працювати без JavaScript і горизонтальної прокрутки при ширині від 320 px. Публікація — GitHub Pages.

**Матеріали.** Тексти та умовну векторну схему створено для цього проєкту. Джерело відомостей про ратушу і фонтани — [туристичний портал Львова](https://lviv.travel/ua/places/attractions/ploshcha-rinok). Схема передає послідовність зупинок і не слугує навігаційною картою.

## Запуск та публікація

Для локального перегляду відкрийте index.html. Або виконайте в папці сайту команду
`python3 -m http.server 8000` і відкрийте http://localhost:8000.

1. Створіть порожній публічний репозиторій lviv-walk на GitHub.
2. Через Upload files завантажте index.html, style.css, route.svg, LICENSE та README.md безпосередньо в корінь репозиторію. Підтвердьте зміни кнопкою Commit changes.
3. У Settings → Pages виберіть Deploy from a branch, гілку main і папку /(root). Збережіть налаштування.
4. Коли розгортання завершиться, відкрийте Visit site. Скопіюйте адресу сайту та окремо адресу репозиторію до звіту.
5. Перевірте публічну адресу через [Nu HTML Checker](https://validator.w3.org/nu/), [PageSpeed Insights](https://pagespeed.web.dev/) і [WAVE](https://wave.webaim.org/). Збережіть скріншоти, режим PageSpeed і фактичні значення FCP та LCP. Виправте помилки у вихідних файлах, опублікуйте зміни та повторіть перевірку.

[Налаштування джерела публікації — GitHub Docs](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
